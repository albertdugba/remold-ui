# Remold

Remold works out **what became what** when an interface changes (no ids, keys or names), then animates, describes and checks the change with Apple-style motion. Open source (MIT), owned by Albert Dugba.

@AGENTS.md

## Who you're working with, and how to teach

- Albert is the owner and future maintainer. He knows JavaScript, TypeScript and React well. **Do not teach programming basics.**
- He is learning the **engine** from scratch (shape maths, springs, matching, the DOM and canvas layers), explained **like he's five**: a story or picture first, then plain words, then code.

## The repo

- Turborepo + pnpm. Packages: `core` (pure TS, no DOM, ES2022 lib only), `dom`, `react`, `vue`, `angular` (directive later via ng-packagr), and `apps/playground` (Vite).
- Each package: tsup (ESM + CJS + d.ts), exports map, Vitest.
- Commands: `pnpm test`, `pnpm typecheck`, `pnpm build`, `pnpm --filter @remold-ui/core test -- --watch`.
- Versions are pinned: TypeScript 5.9.3 (not 7, because tsup doesn't support the native compiler), tsup 8.5.1, Vitest 5.0.3, Turbo 2.11.7, pnpm 10.34.6, Node 24.
- tsconfig is strict, with `noUncheckedIndexedAccess` and `verbatimModuleSyntax`.
- Architecture borrows from React Aria (logic `core` vs DOM layer) and Base UI (compound parts, `data-rm-*` attributes, `--rm-*` CSS variables, controlled and uncontrolled props, a render prop). One core shared by every framework, like Zag.js and TanStack.

## Rules for any code you write in this repo

- The core stays pure: no DOM types in `packages/core`.
- Every transition must be interruptible, carry velocity forward, and have a reduced-motion version that still shows what changed.
- Springs are described as `{ duration, bounce }` (SwiftUI style). Presets: smooth (bounce 0), snappy (0.15), bouncy (0.3), all with duration 0.5.
- Don't hand-draw real companies' logos or artwork. Where Albert asks for brand marks (allowed since 2026-10-20, open source), take them from Simple Icons (CC0) with credit, and say when a brand isn't there.
