# prototypes/

Reference material from the research phase. Not part of any package, not built, not published.

- `remold-motion.html`: the full interactive demo page. Open it in a browser.
- `liquid-split-merge.html`: the metaball split and merge experiment.
- `engine-v0/`: the prototype engine and matcher that produced the benchmark results. Some imports point at files that weren't copied, so read it rather than run it.

The real library is rebuilt from scratch in `packages/`, lesson by lesson (see LEARNING.md).
