Remold is a motion toolkit for interfaces that change. It helps a product feel continuous when content is reordered, filtered, replaced, or moves between states.

When an update happens, Remold compares the previous UI with the next one, finds the elements that correspond, and carries them into their new position with spring motion. You keep rendering your interface normally; Remold handles the transition between its states.

## The problem it solves

Most interfaces are made from repeated changes: a user sorts a list, applies a filter, opens a detail view, receives fresh data, or switches context. Without a transition, the old interface disappears and the next one arrives abruptly.

Many animation tools require you to explicitly pair those states with identifiers such as `layoutId` or `view-transition-name`. That can be useful, but it becomes fragile when the markup is rebuilt by a server response, a different component, or generated content. Remold matches elements from what is on screen—their content, geometry, and surroundings—so it can animate changes without adding animation-only labels to every element.

## How to use it

Start with the smallest surface that changes, then choose the primitive that describes that change.

1. Use [Layout](/docs/primitives/layout) for lists, grids, panels, and route-like changes.
2. Use [Text](/docs/primitives/text), [Icon](/docs/primitives/icon), or [PathGroup](/docs/primitives/path-group) when the content itself changes shape.
3. Use [Scene](/docs/primitives/scene), [Particles](/docs/primitives/particles), or [Canvas](/docs/primitives/canvas) for a visual system that belongs on a canvas.
4. Choose spring settings and respect user preferences with the [motion](/docs/core/motion) and [accessibility](/docs/concepts/accessibility) guides.

For React, wrap the changing region or use a hook around an event-driven update. For any other framework—or plain JavaScript—run the update inside a DOM transition. The [Quick start](/docs/quick-start) shows both paths.

## What is included

- `@remold-ui/react` for React interface components and hooks.
- `@remold-ui/react/canvas` for opt-in React canvas components and hooks.
- `@remold-ui/dom` for transitions on ordinary DOM elements, with any framework or none.
- `@remold-ui/canvas` for scenes, particles, and canvas rendering.
- `@remold-ui/core` for matching, springs, and shape morphing without the DOM.

## A good first path

1. [Install Remold](/docs/installation).
2. Follow the [Quick start](/docs/quick-start) for the React or JavaScript integration that fits your project.
3. Read [how matching works](/docs/concepts/matching) before tuning a complex transition.
4. Browse [components](/docs/components) for copyable patterns, or [primitives](/docs/primitives) to build your own.

Remold is designed to be incremental: begin with one change that currently feels abrupt, then add motion only where it improves clarity.
