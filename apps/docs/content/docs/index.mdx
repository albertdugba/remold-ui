Remold UI is an open-source collection of animated React components, and a small library for morphing. Copy a component into your app, or add Remold's morphs to your own interface.

## What is this?

Two things that work together.

**Components** for the screens you actually ship: inputs, menus, checkouts, dashboards, chat and more. Each one solves a specific product problem and animates only the change that matters. They're built on [Base UI](https://base-ui.com) for behaviour and accessibility, and most of their movement is [Motion](https://motion.dev): springs, enter and exit, shared elements.

**Remold**, for the moments one thing turns into another. It morphs text letter by letter, reshapes icons and SVG paths, rearranges a layout by working out which element became which, keeps connector lines attached, and on canvas re-forms thousands of particles from one shape into the next and springs whole scenes between layouts.

## Not a replacement for Motion or GSAP

Use Motion or GSAP for springs, gestures and enter and exit animations: they are the right tools for that, and most components here use Motion for exactly those. Reach for Remold where a morph says more than a fade. `@remold-ui/morph` only does the geometry of a path morph, so you can drive it from either.

## No animation IDs

Most animation tools need you to pair states by hand, with `layoutId` or `view-transition-name`. Remold matches elements by their content, geometry and surroundings instead, so it keeps working when the markup is rebuilt by a server response, another component or generated content. You render your interface normally.

## Any framework

React gets components and hooks from `@remold-ui/react`. Everywhere else, `@remold-ui/dom` animates any element from plain JavaScript, so it works with Vue, Svelte, Astro or a server-rendered page. `@remold-ui/canvas` draws scenes and particles, and `@remold-ui/core` is the matching and spring maths on its own, with no DOM at all.

## You own the code

Components are distributed through a [shadcn registry](/docs/registry). Installing one drops its source and CSS into your project, where you can read it, change it and version it like anything else you wrote. Remold itself is a normal package you update when you choose.

## Accessible by default

Remold follows the system's reduced-motion setting: changes happen at once instead of animating. Morphing text stays real text for screen readers, and focus stays on the element you were on when it's replaced.
