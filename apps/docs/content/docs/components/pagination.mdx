## Things to try

- **Pick a page.** The raised chip slides over to it instead of jumping, and the range underneath changes only the digits that differ.
- **Walk past page 4.** The window starts moving: pages ahead slide in, pages behind slide out, and the row stays the same width so nothing under your pointer moves away.
- **Hover the dots.** They turn into a double arrow; click to jump five pages.
- **Reach either end.** The arrow on that side dims and stops.

## How it works

- **One number.** `page` works controlled or uncontrolled; pass the `total` and how many `siblings` to show either side of the current page.
- **Always the same count.** `pageItems` always returns the same number of items (first, last, the current page and its siblings, and up to two gaps), so the row never grows or shrinks as you page.
- **Items that move, not reprint.** Each number is keyed by its page, so Motion's `layout` slides the ones that stay and `AnimatePresence` fades the ones that come and go; the current page is a single `layoutId` chip.
- **Text that changes in place.** The "Showing 41–50" line is a Remold `Text`, so only the changed digits move.
- **Accessible.** It's a labelled `nav` with a list of buttons; the current page has `aria-current="page"`, the arrows and gaps say what they do, and each change is announced.
