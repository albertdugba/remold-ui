CSS can change a variable font's weight or width. It can't bend a letter around the pointer or turn a word into a logo. Remold reads the glyph outlines and treats them like any other shape.

Tools that split text into letters move whole letters. These change the letters' outlines, and the real text stays in the page for search and screen readers.

## How it works

1. **Outlines.** Each letter's outline comes from the font file, read once at build time and kept as SVG path data. Kerning comes along, so the word is spaced as the font intends.
2. **Bending.** The outlines are cut into short curves with `subdivide` from `@remold-ui/core`, and every point is moved by a soft field round the pointer, every frame. The pointer's position and strength are springs, so the bend eases in and out.
3. **Morphing.** `createMorph(word, logo)` pairs the letters' pieces with the logo's pieces and returns a path for any point in between. A spring drives it, so it can be interrupted or scrubbed.

```ts
import { createMorph } from "@remold-ui/core";

const morph = createMorph(wordPath, logoPath, { pairing: "auto" });
path.setAttribute("d", morph.d(t));
```

Switch to **Drawing order** to see what the pairing buys you: pieces paired in the order they were drawn fly across the word to reach their partner.
