## Things to try

- **Switch two-factor on.** The setup opens between the rows and "Sign-in alerts" steps down to make room.
- **Type any six digits, or paste them.** Once the code is full it's accepted, and the setup folds into "On · Authenticator app".
- **Switch it off.** Everything returns to where it was.

## How it works

- **The setup unfolds by its height.** Motion springs it from nothing to its natural height with just a touch of give, so "Sign-in alerts" is pushed down smoothly rather than jumping. What's inside fades in once there's room for it. Closing runs the other way: the contents fade out first, and only then does the box fold, so its shrinking edge never cuts through the code or the QR. The box only ever changes height, so no words stretch.
- **The status line swaps in place.** "Ask for a code when signing in" lifts away as "On · Authenticator app" settles in.
- **The switches slide.** Each knob is a Base UI Switch thumb that Motion springs along its track, so it slides to the other end instead of jumping there, and the track's colour fades with it.
- The code boxes sit over one real input, so typing, pasting and one-time-code autofill all work as usual.
- The QR code is drawn. Put your real one in its place.
