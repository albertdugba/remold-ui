## Things to try

- **Type a word and press comma.** The chip forms around the word without it moving.
- **Pick a suggestion.** Existing tags are offered as you type; a new word is offered as a new tag.
- **Press Backspace in an empty field.** The last tag comes off.

## How it works

- **Built on Base UI.** `Combobox` in `multiple` mode gives the chips, the suggestions, keyboard navigation and removal.
- **The text becomes the chip.** A new chip starts with no padding and no fill, exactly where the typed text sat, then both grow in with Motion.
