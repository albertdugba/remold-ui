It plays a short scene while it's on screen. Touch it and it's yours.

## Things to try

- **Click an issue's status to complete it.** The row leaves its group, and its ID travels down into the folded Done row with the latest others.
- **Open Done.** The IDs spread out of the folded row into rows of their own, newest first.
- **Reopen a done issue.** It goes back to its own place in Todo or In Progress, and the rows around it make room.

## How it works

- An issue's row and its ID in the folded Done row are different markup in different places. Motion gives both the same `layoutId`, so the issue travels between them instead of vanishing.
- Opening Done is the same shared-layout transition in reverse: each ID in the folded row becomes the ID of a row.
- Groups are just filtered from one list of issues and rendered again. Nothing tracks positions, so a reopened issue lands back in its original place.
- Completing is pretend. Save it in `toggle`, and pass your own `ISSUES`.
