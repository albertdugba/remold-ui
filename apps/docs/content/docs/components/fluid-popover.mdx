## Things to try

- **Open the menu.** The ellipsis grows into the tray around itself, and the rows blur in one after another from the top.
- **Pick an action.** The rows blur out, the tray folds back, and for a moment the button shows a green check for what you did.

## The split of responsibilities

Use Base UI's `Popover` for the things that must be correct: anchored positioning, focus, Escape, and outside-click dismissal. Motion drives one clipped tray: the ellipsis key expands into the menu, ending up in its top-right corner as the close button, then the rows rise out from beneath it.

Afterwards the trigger says what happened. It shows a check for a moment before going back to the ellipsis, and screen readers hear the same thing ("Split request sent", "Receipt link copied").

## Details worth keeping

- The tray is one element, rather than a trigger plus a detached popup card.
- The tray expands from the trigger's centre; menu rows arrive only after there is room for them.
- Closing runs the other way: the rows blur out first (Base UI waits for the popup's `data-ending-style` transition), then the tray shrinks back around the trigger.
- Reduced-motion users get an opacity-only transition.
