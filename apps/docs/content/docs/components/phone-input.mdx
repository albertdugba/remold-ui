## Things to try

- **Type a number.** Spaces appear as the number reaches them.
- **Search countries.** Search by name, country abbreviation, or dialing code across the ten example countries.
- **Change the country.** The same digits regroup into the new format when the input is not focused. Extra digits are preserved and a length hint appears.
- **Paste a full number.** A pasted country code or leading zero is dropped.

## How it works

- **Built on Base UI.** `Field` gives the label and description, and `Combobox` provides the searchable country picker.
- **Native editing.** The real input is visible while focused, supporting caret placement, selection, and deletion. The formatted animated preview returns on blur.
- **Separators slide.** Digits are keyed by their position and separators by their order, so a space shared by both formats moves instead of being redrawn.
