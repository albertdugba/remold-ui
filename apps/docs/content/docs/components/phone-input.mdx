## Things to try

- **Type a number.** Spaces appear as the number reaches them.
- **Change the country.** The same digits regroup into the new format, and the spaces that both formats share slide across.
- **Paste a full number.** A pasted country code or leading zero is dropped.

## How it works

- **Built on Base UI.** `Field` gives the label and description, and `Select` is the country picker.
- **A real input underneath.** An invisible input covers the number, so typing, pasting and autofill work as usual. The digits you see are drawn from its value.
- **Separators slide.** Digits are keyed by their position and separators by their order, so a space shared by both formats moves instead of being redrawn.
