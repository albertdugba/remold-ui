Choose an icon. Nothing is paired by hand: Remold matches the strokes of the previous icon to the next one and springs each one into place, so any icon can become any other.

## Install

<AddCommand name="morph-icons" />

Or morph any icon yourself with [Icon](/docs/primitives/icon). Pass the icon component (or element) as it is:

```tsx
import { Remold } from "@remold-ui/react";
import { Volume2, VolumeX } from "lucide-react";

<Remold.Icon icon={muted ? VolumeX : Volume2} className="size-5" />;
```

It works with any icon set, or your own SVG components: Remold reads each icon's paths, circles, rectangles and lines, and takes its stroke and fill from the icon.

## Which icons morph best

Any icon can become any other, but some pairs look better than others:

- **Same set, same style.** Outline icons from one set share a stroke width and grid, so their strokes line up. Morphing between an outline icon and a filled one works, but the look jumps.
- **Similar numbers of strokes.** When one icon has more strokes than the other, the extra ones grow out of the nearest stroke instead of appearing from nowhere, but a 2-stroke icon becoming a 12-stroke one is busy.
- **No transforms.** An icon whose SVG uses `transform` is shown as it is, without morphing, and a warning says which element to flatten.

<Callout>The icons are from [Lucide](https://lucide.dev), an open-source icon set (ISC licence).</Callout>
