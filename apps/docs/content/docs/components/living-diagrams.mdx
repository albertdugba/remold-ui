Each diagram is a list of objects, the links between them, and a few named layouts. Remold draws it on a canvas and springs between layouts, so you never lose track of a piece. People can turn it, tap an object to focus it, or tab through it with a screen reader.

## Things to try

- **Database:** press Sharded and the single database splits into three shards. Replicated merges them back and grows two copies.
- **Edge network:** compare one origin with requests served from edge locations near people.
- **Integrations:** switch layouts and drag the scene while it moves. Nothing stutters.
- Hover to lift a piece, click to focus it, and drag sideways to turn the scene.

## Usage

```tsx
<Remold.Scene
  label="A database that shards and replicates"
  objects={{ s1: { look: "cylinder", label: "a–f" }, api: { look: "chip", label: "api" } /* … */ }}
  layouts={{
    Single: {
      /* … */
    },
    Sharded: {
      /* … */
    },
    Replicated: {
      /* … */
    },
  }}
  links={[{ from: "api", to: "s1", flow: true, layouts: ["Sharded"] }]}
  layout={layout}
/>
```

See [Scene](/docs/primitives/scene) for every option.
