## Things to try

- **Tick a row, then shift-click another.** Everything between is selected, and neighbouring picks join into one band.
- **Watch the header box.** It shows when some or all of the rows are selected.
- **Look at the foot.** The hint gives way to an action bar whose count rolls as the selection grows.
- **Delete.** The chosen rows fold away one after another, and the bar offers Undo.

## How it works

- **TanStack Table models it.** `useReactTable` holds the columns, the row model and row selection, so select-all, the header's mixed state and each row's checkbox read from one selection. Swap in your own data and columns and the rest keeps working.
- **Base UI draws the controls.** The checkboxes are Base UI's Checkbox.
- **Motion moves it.** The joined bands, the rolling count and the rows folding away are Motion.
