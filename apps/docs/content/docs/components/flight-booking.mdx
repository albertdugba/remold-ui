## Things to try

- **Choose an alternative.** The selected row grows into an updated boarding pass while the delay context and the other option step out of the way.
- **Change the seat.** The seat on the pass opens the compact seat selector. Pick a seat and it returns to the same pass with the new number already in place.
- **Go back** with the arrow. The pass settles back into the alternatives it came from.

## How it works

- **The row becomes the pass.** Motion owns the selected surface as it expands from an alternative into a boarding pass.
- **One card, three jobs.** The flight row, boarding pass and seat selector are deliberate states of one surface. That keeps the interaction understandable even while its contents become more detailed.
- **Keep shapes light.** The QR code is drawn as one path, keeping the component compact.
- **One state transition at a time.** A choice can interrupt movement and continue naturally toward its new state.
