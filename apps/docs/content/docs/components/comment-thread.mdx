A post from an indie developer, Ama Mensah, about shipping her first open-source library, and the readers replying to it. Press play to watch a short scene, or join in yourself.

## Things to try

- **Watch the typing.** "Abena is typing…" is a small bubble that grows into her comment when it's sent, and Ama's answer arrives the same way.
- **Reply.** Yours appears at once marked "Sending…", its line drawing in. When the server confirms it, only the label changes.
- **Hover a reply.** The lines from the top down to it darken, and everything off that path fades.
- **Like** the post or any comment, and the count ticks over.
- **Hide replies.** The branch folds into a pill with the repliers' faces, and its lines retract.
- **Sort** by Top or Newest. Whole branches move, lines and all.

## How it works

- Every avatar is an anchor (`data-rm-anchor`), and a reply's avatar links to its parent's (`data-rm-link`). [Connectors](/docs/primitives/connectors) draws the lines.
- Motion owns each comment's layout animation when a reply arrives, a branch folds, or the order changes. `useConnectorMotion(connectorRef)` refreshes Remold's SVG paths for the duration, keeping the lines attached without competing for transforms.
- **Typing becomes the comment.** The typing indicator is replaced by the sent comment, while the surrounding comments settle into their new positions with a short, interruptible spring.
- **Lit lines.** Each avatar on the hovered path carries `data-rm-line="lit"`. Connectors copies it onto the line drawn to that avatar as `data-line`, so CSS can make those lines glow.

### Optimistic replies

A reply is shown before the server has it. Keep its client id when the server confirms it: Motion retains its layout identity, while the connector's anchor stays attached to the same reply.
