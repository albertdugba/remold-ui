Every object above comes from one function, `extrude()` in `@remold-ui/canvas`. Give it a rectangle, an ellipse or **any SVG path data**, and it pushes the shape up into a solid. The star's points and the gear's teeth are concave, the ring and the gear have holes, and the tray is hollowed out, so the scene draws each wall separately, far to near, rather than filling one outline.

## The pieces

```ts
import { caption, extrude } from "@remold-ui/canvas";

// A thick block with streaks of light in its sides, a glowing rim and an icon on top.
const block = extrude({ radius: 0.16, height: 36, sides: "sheen", edge: true, decal: { icon: wave } });

// A thin card with its label along one edge.
const card = extrude({ height: 10, decal: { align: "start", rotate: -90 } });

// A tray: the top hollowed out 7% in from the rim, 80% of the way down.
const tray = extrude({ height: 74, sides: "sheen", well: { inset: 0.07, depth: 0.8 } });

// Any outline at all: path data in, a solid out. Inner outlines are holes.
const heart = extrude({ shape: { path: "M50 92C20 70 4 52 4 32A22 22 0 0 1 50 22A22 22 0 0 1 96 32C96 52 80 70 50 92Z" } });
```

Use them as the `look` of any object in a [Scene](/docs/primitives/scene). `caption` is a label that always faces the screen; join it to something with a dashed link to make a callout. The `ink` palette gives near-black tops with violet light in the sides.

| Option    | What it does                                                                                  |
| --------- | --------------------------------------------------------------------------------------------- |
| `shape`   | `"rect"`, `"ellipse"`, or `{ path }` with SVG path data, stretched to the object's footprint. |
| `radius`  | Corner rounding for `"rect"`, as a fraction of the shorter side.                              |
| `height`  | Thickness when a layout doesn't give one.                                                     |
| `sides`   | `"gradient"`, `"flat"`, or `"sheen"` for bright streaks.                                      |
| `edge`    | A glowing rim round the top.                                                                  |
| `well`    | Hollow the top into a tray: `{ inset, depth }`, both 0 to 1.                                  |
| `decal`   | Text or an SVG icon on the top face: `text`, `icon`, `align`, `rotate`, `size`, `color`.      |
| `passive` | Not hovered, focused or reachable by keyboard: for decoration.                                |
