## Things to try

- **Drop a file on it, or click it.** The whole box is the button; dragging a file over it wakes it up.
- **Watch it upload.** The same box shows the file, the percentage rolls and a hairline fills along the bottom.
- **Wait for it.** The arrow reshapes into a check, “Uploading” morphs into “2.4 MB · Uploaded”, and the hairline fades.
- **Remove it.** The box goes back to being a drop area.

## How it works

- **One box.** Nothing is swapped for something else: the drop area, the upload and the finished file are the same element, so the dashed edge simply turns solid.
- **Built on Base UI.** `Field` holds a real file input, and `Progress` gives the upload its value for screen readers.
- **Remold for the two changes that matter.** The icon's arrow reshapes into a check with `Remold.Icon`, and `Remold.Text` turns “Uploading” into “Uploaded”, keeping the letters they share. The percentage rolls with the Odometer instead, so it doesn't re-morph on every tick.

<Callout>The upload is simulated; nothing leaves your device.</Callout>
