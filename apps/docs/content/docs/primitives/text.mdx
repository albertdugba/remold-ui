## Installation

<Install packages="@remold-ui/react" />

Using plain JavaScript? Install `@remold-ui/dom` instead.

## Usage

```tsx tab="React" tab-group="lang"
<Remold.Text>{status}</Remold.Text>
```

```js tab="JavaScript"
import { morphText } from "@remold-ui/dom";

morphText(label, status);
```

Letters the old and new text share stay on screen and slide into place; the rest fade out and in. It renders a `span`, and screen readers get the whole new text at once.
