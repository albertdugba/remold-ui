The orb is one `draw` function. Each state is a set of `values` (size, drift speed, breathing, how tightly the clouds gather), so switching state springs every number from wherever it is, even mid-change.

## Installation

<Install packages="@remold-ui/react" />

Import canvas primitives from `@remold-ui/react/canvas` so canvas rendering stays out of your interface-only entry point.

Using plain JavaScript? Install `@remold-ui/canvas` instead, and use [painter()](/docs/canvas/painter).

## Usage

Write `draw`. Pass the numbers it reads as `values`; change them and they spring there.

```tsx tab="React" tab-group="lang"
import { Remold } from '@remold-ui/react/canvas';

<Remold.Canvas
  values={{ radius: active ? 80 : 40 }}
  draw={(context, { width, height, values }) => {
    context.beginPath();
    context.arc(width / 2, height / 2, values.radius, 0, Math.PI * 2);
    context.fill();
  }}
  className="h-64 w-full"
/>
```

```js tab="JavaScript"
import { painter } from "@remold-ui/canvas";

const orb = painter(canvas, {
  values: { radius: 40 },
  draw(context, { width, height, values }) {
    context.beginPath();
    context.arc(width / 2, height / 2, values.radius, 0, Math.PI * 2);
    context.fill();
  },
});

orb.to({ radius: active ? 80 : 40 });
```

What you don't write:

- **Sizing.** The canvas stores enough pixels to be sharp on every screen (capped at 2×), refits when it resizes, and is cleared and scaled before each frame. Draw in CSS pixels from `(0, 0)` to `(width, height)`.
- **The frame loop.** It runs while a value is springing and stops when they settle. Off screen, it pauses.
- **Springs.** `values` become springs. A new target starts from the current position and speed, so interrupting is smooth.
- **Reduced motion.** Values jump instead of springing, `continuous` drawing stops, and `draw` gets `still: true` so you can paint a calm frame.

## Things that move on their own

Set `continuous` for drift, breathing, or anything that follows live input like audio. `draw` then runs every frame, with `time` and `dt` in seconds. Keep per-frame state in a ref.

```tsx tab="React" tab-group="lang"
<Remold.Canvas
  continuous
  values={LOOKS[state]}
  spring={{ duration: 0.7, bounce: 0 }}
  draw={(context, { width, values, time, dt }) => {
    drift.current += values.flow * dt;
    // paint with time, drift.current and values
  }}
/>
```

```js tab="JavaScript"
let drift = 0;

const orb = painter(canvas, {
  continuous: true,
  values: LOOKS.idle,
  spring: { duration: 0.7, bounce: 0 },
  draw(context, { width, values, time, dt }) {
    drift += values.flow * dt;
    // paint with time, drift and values
  },
});

orb.to(LOOKS[state]);
```

## Gestures

`actionsRef` gives you `to`, `set`, `values` and `still` for event handlers. In plain JavaScript they're on the object `painter()` returns. Follow a finger with `set`, then hand the flick over with `to` and a `velocity`:

```tsx tab="React" tab-group="lang"
const actions = useRef<Remold.CanvasActions<{ turn: number }>>(null);

<Remold.Canvas
  actionsRef={actions}
  values={{ turn: 0 }}
  spring={{ turn: springs.smooth }}
  onPointerMove={(e) => actions.current?.set({ turn: start + e.clientX - x })}
  onPointerUp={() => actions.current?.to({ turn: landing }, { velocity: { turn: speed } })}
  draw={draw}
/>
```

```js tab="JavaScript"
const wheel = painter(canvas, { values: { turn: 0 }, spring: { turn: springs.smooth }, draw });

canvas.addEventListener("pointermove", (e) => wheel.set({ turn: start + e.clientX - x }));
canvas.addEventListener("pointerup", () => wheel.to({ turn: landing }, { velocity: { turn: speed } }));
```

`spring` takes one spring for every value, or one per name.

## API reference

| Prop            | Type                                   | Default   | Description                                                                 |
| --------------- | -------------------------------------- | --------- | --------------------------------------------------------------------------- |
| `draw`          | `(context, frame) => void`             |           | Paints a frame. `frame` has `width`, `height`, `pixelRatio`, `values`, `time`, `dt`, `still`. |
| `values`        | `Record<string, number>`               |           | Numbers `draw` reads. New targets spring.                                   |
| `spring`        | `SpringConfig \| Record<name, SpringConfig>` | smooth | How values spring.                                                          |
| `continuous`    | `boolean`                              | `false`   | Draw every frame, not only while springing.                                 |
| `clear`         | `boolean`                              | `true`    | Clear before each frame. Turn off to paint trails.                          |
| `label`         | `string`                               |           | Accessible name. Leave it out for a decorative canvas.                      |
| `reducedMotion` | `"user" \| "always" \| "never"`         | `"user"`  | Follow the system setting, or override it.                                  |
| `maxPixelRatio` | `number`                               | `2`       | Cap on stored pixels per CSS pixel.                                         |
| `actionsRef`    | `Ref<CanvasActions>`                   |           | `to`, `set`, `redraw`, `values`, `still`.                                   |

Every other prop goes to the `<canvas>`.

In plain JavaScript, [painter()](/docs/canvas/painter) takes the same options apart from `actionsRef`, and returns the actions itself.
