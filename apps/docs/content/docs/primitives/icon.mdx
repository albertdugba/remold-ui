## Usage

Pass the icon you'd normally render, as a component or an element:

<CodeVariants>
<Variant framework="react">

```tsx
import { Remold } from "@remold-ui/react";
import { Menu, X } from "lucide-react";

<Remold.Icon icon={open ? X : Menu} className="size-5" />;
```

</Variant>
<Variant framework="js">

```ts
import { createMorph, value } from "@remold-ui/core";
import { frames, iconToPath } from "@remold-ui/dom";

// Any two icons on the page (hidden is fine): read each into one path.
const menu = iconToPath(document.querySelector("#icon-menu"))!.d;
const close = iconToPath(document.querySelector("#icon-close"))!.d;
const path = document.querySelector("#toggle path");

let shown = menu;
function morphTo(next: string) {
  const morph = createMorph(shown, next, { padding: "merge" });
  const t = value(0, { spring: { duration: 0.4, bounce: 0.15 } });
  t.to(1);
  frames((dt) => {
    t.step(dt);
    shown = morph.d(t.current);
    path.setAttribute("d", shown);
    return !t.settled;
  });
}

button.addEventListener("click", () => morphTo(open ? close : menu));
```

</Variant>
</CodeVariants>

It works with any icon set, or your own SVG components and inline `<svg>`. Remold reads the icon's shapes (paths, circles, ellipses, rectangles, lines, polylines and polygons) into one path, and takes its viewBox, fill and stroke from the icon. Props you set yourself, such as `strokeWidth`, win. When the next icon has more strokes or fewer, spare strokes grow out of a neighbour or merge into one.

On the server, and on the first paint in the browser, the icon is rendered exactly as it is. Remold takes over before the first frame is drawn, so there's no flash.

### Path data

If your icons are path data rather than components, pass `d` instead. Several strokes go in one path:

<CodeVariants>
<Variant framework="react">

```tsx
<Remold.Icon d={open ? "M6 6l12 12M18 6 6 18" : "M4 7h16M4 12h16M4 17h16"} fill="none" stroke="currentColor" strokeWidth={2} />
```

</Variant>
<Variant framework="js">

```ts
// With path data, skip iconToPath and morph straight between the strings.
morphTo(open ? "M6 6l12 12M18 6 6 18" : "M4 7h16M4 12h16M4 17h16");
```

</Variant>
</CodeVariants>

### Limits

- An icon whose SVG uses `transform` can't be read as one path. It's shown as it is, without morphing, and a warning names the element to flatten.
- One look per icon: if an icon's shapes are painted differently from each other (a filled dot inside an outline icon), they all take the icon's own look while it morphs.
