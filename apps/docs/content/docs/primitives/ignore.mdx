## Installation

<Install packages="@remold-ui/react" />

Using plain JavaScript? Install `@remold-ui/dom` instead.

## Usage

```tsx tab="React" tab-group="lang"
<Remold.Morph trigger={view}>
  <Remold.Ignore>
    <LiveChart />
  </Remold.Ignore>
</Remold.Morph>
```

```js tab="JavaScript"
import { transition } from "@remold-ui/dom";

chart.setAttribute("data-rm-ignore", "");
transition(dashboard, () => showView(view));
```

Anything inside is left out of transitions: it isn't measured, paired or moved. Use it for videos, live charts and anything that animates by itself. It renders a `span` with `data-rm-ignore`; you can put that attribute on any element instead.
