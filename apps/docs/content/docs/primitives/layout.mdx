## Usage

<CodeVariants>
<Variant framework="react">

```tsx
import { Remold } from "@remold-ui/react";

<Remold.Layout trigger={view}>{/* anything that changes when `view` does */}</Remold.Layout>;
```

</Variant>
<Variant framework="js">

```ts
import { transition } from "@remold-ui/dom";

const root = document.querySelector("#files");

// Wrap any change to the page. Remold reads it before and after, and animates the difference.
transition(root, () => {
  root.innerHTML = renderFiles(files, view);
});
```

</Variant>
</CodeVariants>

`trigger` is any value that changes when the content does: a view, a sort order, a route. Layout reads the page during the render in which it changes and animates after React commits, so it works with any state library. It renders a `div`.

When more than one thing can change, pass them as a list. It's compared item by item, like an effect's dependencies, so a new array with the same items doesn't animate:

<CodeVariants>
<Variant framework="react">

```tsx
<Remold.Layout trigger={[view, sort, filter]}>
```

</Variant>
<Variant framework="js">

```ts
// No trigger needed: wrap each change, whatever caused it.
for (const control of [viewToggle, sortSelect, filterInput]) {
  control.addEventListener("change", () => {
    transition(root, () => renderPeople(root, { view, sort, filter }));
  });
}
```

</Variant>
</CodeVariants>

## Examples

### Different markup for each view

The grid and the list below are rendered by different elements. Remold pairs each person by what they show, not by where they sit in the tree.

<Stage code={<Source demo="layout" />}>
  <LayoutDemo />
</Stage>

<CodeVariants>
<Variant framework="react">

```tsx
<Remold.Layout trigger={view}>{view === "Grid" ? <PeopleGrid people={people} /> : <PeopleList people={people} />}</Remold.Layout>
```

</Variant>
<Variant framework="js">

```ts
transition(root, () => {
  // Different markup each time; people are matched by what they show.
  root.innerHTML = view === "Grid" ? peopleGrid(people) : peopleList(people);
});
```

</Variant>
</CodeVariants>

### Announcing changes

<CodeVariants>
<Variant framework="react">

```tsx
<Remold.Layout trigger={sort} announce={(s) => `Sorted. ${s.moved} files moved.`}>
```

</Variant>
<Variant framework="js">

```ts
transition(list, () => renderFiles(list, files, sort), {
  announce: (summary) => `Sorted. ${summary.moved} files moved.`,
});
```

</Variant>
</CodeVariants>
