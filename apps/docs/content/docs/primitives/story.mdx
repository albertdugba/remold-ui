## Installation

<Install packages="@remold-ui/react" />

Story is React only for now. The canvas underneath is [scene()](/docs/canvas/scene) from `@remold-ui/canvas`, which you can drive from plain JavaScript.

## Usage

A Story is a [Scene](/docs/primitives/scene) told in chapters. Each chapter picks a layout, an object to focus and an annotation that follows the object around the canvas.
