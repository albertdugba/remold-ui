## Usage

<CodeVariants>
<Variant framework="react">

```tsx
<Remold.Scene label="Our architecture" objects={objects} layouts={layouts} layout={layout} />
```

</Variant>
<Variant framework="js">

```ts
import { scene } from "@remold-ui/canvas";

const diagram = scene(canvas, { label: "Our architecture", objects, layouts });

// Spring every object, link and the camera to another layout.
diagram.to("scaled");
```

</Variant>
</CodeVariants>

Describe the objects once and each layout as plain data: where every object sits, and the camera. Changing `layout` springs every object, link and the camera to the new arrangement. People can drag to turn the scene, tap an object to focus it, or tab through the objects with a screen reader. Without React, use [scene()](/docs/canvas/scene).
