## All parts

| Part                                      | What it's for                                                                   |
| ----------------------------------------- | ------------------------------------------------------------------------------- |
| [Morph](/docs/primitives/morph)           | Morph everything inside it when a value changes: lists, grids, views, routes. |
| [Text](/docs/primitives/text)             | Change text letter by letter.                                                   |
| [Icon](/docs/primitives/icon)             | Reshape an SVG icon from one state into the next.                               |
| [PathGroup](/docs/primitives/path-group)  | Morph a chart or illustration made of several paths.                            |
| [Scene](/docs/primitives/scene)           | Spring a canvas diagram between layouts.                                        |
| [Story](/docs/primitives/story)           | Tell a Scene in chapters with annotations.                                      |
| [Particles](/docs/primitives/particles)   | Rebuild thousands of dots into any shape.                                       |
| [Canvas](/docs/primitives/canvas)         | Paint your own canvas; sizing, the frame loop and springs are handled.          |
| [Connectors](/docs/primitives/connectors) | Lines between elements that stay attached while they move: trees and threads.   |
| [Tour](/docs/primitives/tour)             | Walk people through an interface one step at a time, in any style.              |
| [Ignore](/docs/primitives/ignore)         | Leave something out of transitions.                                             |

For changes you make from an event handler, see [useRemold](/docs/hooks/use-remold).
