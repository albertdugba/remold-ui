## Usage

Mark the points lines run between with `Remold.Anchor`: give each a `name`, and `linkTo` the anchor its line comes from. Put a [Layout](/docs/primitives/layout) inside, and the lines follow every element while it moves.

<CodeVariants>
<Variant framework="react">

```tsx
import { Remold } from "@remold-ui/react";

<Remold.Connectors radius={12}>
  <Remold.Layout trigger={thread}>
    {comments.map((c) => (
      <article key={c.id}>
        <Remold.Anchor name={c.id} linkTo={c.parentId} render={<Avatar user={c.author} />} />
        <p>{c.text}</p>
      </article>
    ))}
  </Remold.Layout>
</Remold.Connectors>;
```

</Variant>
<Variant framework="js">

```ts
import { connectors, transition } from "@remold-ui/dom";

// In your markup, name each point and the one its line comes from:
// <img data-rm-anchor="c2" data-rm-link="c1" />

// `svg` is laid over `thread`: absolutely positioned, the same size.
const lines = connectors(thread, svg, { radius: 12 });

// Lines follow the elements while a transition moves them.
transition(thread, () => renderComments(thread, comments));
```

</Variant>
</CodeVariants>

`linkTo` can be `undefined` for anchors with no line coming in, like the top-level comments. `Anchor` renders a `span`; `render` puts the anchor on your own element instead. Under the hood it's two attributes, `data-rm-anchor` and `data-rm-link`, which you can also write yourself.

- Lines start under the anchor's middle and end at the left side of the linked element, so they suit trees and threads where children sit below and to the right.
- A line that appears draws itself in; a line whose element goes draws itself out. Lines that are there when the page loads are simply there.
- With reduced motion, lines still follow the elements, but appear and disappear at once.
- Style them with CSS: each line is a `path.rm-connector`. Lines drawing in or out carry `data-rm-drawing`.
- Give the linked element `data-rm-line="something"` and its line gets `data-line="something"`: a way to style one line differently, like lighting up the path to a hovered reply.

```css
.my-tree .rm-connector {
  stroke: #cbd5e1;
  stroke-width: 1.5;
}

.my-tree .rm-connector[data-line="lit"] {
  stroke: #a78bfa;
  filter: drop-shadow(0 0 6px #a78bfa);
}
```

### Without React

```ts
import { connectors } from "@remold-ui/dom";

// `svg` is laid over `root`: absolutely positioned, the same size.
const lines = connectors(root, svg, { shape: "elbow", radius: 12 });
lines.destroy();
```
