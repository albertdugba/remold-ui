---
title: "useViewTransition"
description: "Run a change through the browser's View Transitions API, with Remold pairing the elements."
---

## Usage

```tsx tab="React" tab-group="lang"
const { ref, animate } = useViewTransition();

<main ref={ref}>
  <button onClick={() => animate(() => setPage("detail"))}>Open</button>
</main>;
```

```js tab="JavaScript"
import { viewTransition } from "@remold-ui/dom";

openButton.addEventListener("click", () => {
  viewTransition(main, () => {
    main.innerHTML = renderDetail(item);
  });
});
```

Best for large, route-sized changes, which the browser animates off the main thread. View transitions can't be interrupted, so it falls back to [useRemold](/docs/hooks/use-remold) where the API is missing, when reduced motion is on, or for very large pages.
