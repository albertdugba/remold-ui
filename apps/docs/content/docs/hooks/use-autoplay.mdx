---
title: "useAutoplay"
description: "Step through states by itself while on screen, and stop when someone takes over: for landing-page demos."
---

## Usage

```tsx
import { Remold, useAutoplay } from "@remold-ui/react";

function Showcase() {
  const autoplay = useAutoplay(VIEWS.length, { every: 2000 });
  return (
    <section ref={autoplay.ref}>
      <Remold.Layout trigger={autoplay.step}>{renderView(VIEWS[autoplay.step])}</Remold.Layout>
      <button {...autoplay.toggleProps}>{autoplay.playing ? "Pause" : "Play"}</button>
    </section>
  );
}
```

React only for now. In plain JavaScript, step your own state on a timer and run each change through `transition` from `@remold-ui/dom`.

- It only plays while the element with `ref` is on screen, so a page full of demos doesn't run them all at once.
- The first click, tap or key press inside the element stops it for good: the person is in charge now. The button with `toggleProps` is the exception, so it can pause and play.
- Give the steps different lengths with a function: `every: (step) => (step === last ? 4000 : 2000)`.
- Anything that moves by itself for more than five seconds needs a way to pause it (WCAG 2.2.2). `toggleProps` makes any button that control.

## Options

  type={{

## Returns

| Field                       | What it is                                                |
| --------------------------- | --------------------------------------------------------- |
| `ref`                       | Put it on the element that holds the demo.                |
| `step`                      | The current step, from 0 to `count - 1`.                  |
| `setStep(step)`             | Go to a step yourself.                                    |
| `next()`                    | Go to the next step, wrapping round.                      |
| `playing`, `setPlaying(on)` | Whether it's playing.                                     |
| `toggleProps`               | Spread on a button to make it the play and pause control. |
