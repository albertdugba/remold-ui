## React

<Install packages="@remold-ui/react" />

React 18 or later. The package ships ES modules, CommonJS and TypeScript types.

## JavaScript

Not using React? `@remold-ui/dom` works on any element, with any framework or none: Vue, Svelte, Astro, server-rendered pages, or a plain `<script type="module">`.

<Install packages="@remold-ui/dom" />

```js
import { transition } from "@remold-ui/dom";

const list = document.querySelector("#inbox");

sortButton.addEventListener("click", () => {
  transition(list, () => {
    list.replaceChildren(...sortByDate(messages).map(renderMessage));
  });
});
```

`transition` reads the page, runs your update, and animates what changed. The [quick start](/docs/quick-start) shows each step in both.

## Canvas and core

Install `@remold-ui/canvas` for scenes and particles, or `@remold-ui/core` on its own for the matching and spring maths, for example in a Web Worker or on the server.

<Callout>Everything is tree-shakeable. Importing `Remold.Text` doesn't pull in the canvas code.</Callout>
