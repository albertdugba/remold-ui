Every example on this site is in a [shadcn](https://ui.shadcn.com/docs/registry) registry. One command copies the component, every file it uses and its CSS into `components/remold/` in your project, and installs the Remold packages it needs. The code is yours from then on: change it however you like.

<AddCommand name="morph-icons" />

Assistants that use the shadcn MCP server can install them too: ask for "the Remold morph icons" and point it at this registry.

## What's in it

| Name                   | What it is                                                          |
| ---------------------- | ------------------------------------------------------------------- |
| `course-outline`       | A course outline whose lines follow modules and lessons.            |
| `comment-thread`       | A post and the conversation under it, with live typing and lit reply paths. |
| `morph-icons`          | 44 outline icons that morph into each other.                        |
| `letters`              | Letters you can bend, and a word that morphs into a logo.           |
| `files`                | A list that sorts and filters.                                      |
| `layout`               | People as cards or rows.                                            |
| `text`                 | A status label and a price that morph.                              |
| `icons`                | Toggle buttons with morphing icons.                                 |
| `feedback-face`        | A rating face whose parts each morph.                               |
| `scene`                | An isometric canvas scene.                                          |
| `story`                | A scene that steps through a story.                                 |
| `particles`            | Text and shapes as flowing dots.                                    |
| `match-lines`          | Draws what Remold paired.                                      |

Replace the name at the end of the command with any of these. The full list is at [`/r/registry.json`](/r/registry.json).

## Colours

The components use your theme's colours when it defines Fumadocs-style variables (`--color-fd-background`, `--color-fd-border` and so on), and fall back to neutral light colours when it doesn't. Change them in the copied CSS.
