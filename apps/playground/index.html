Remold playground

Markup rewritten from scratch

Each button replaces the HTML below with brand-new markup: no keys, no ids. transition(stage, update) works out what became what and springs every element from where it was. Click another view mid-flight to interrupt it.

React

<Remold.Root trigger={sort}> from @remold-ui/react. Every item gets a brand-new key on each change, so React rebuilds them all, and Remold still works out which is which. The status is <Remold.Text>; the canvas is <Remold.Scene layout={layout}>.

Illustrations that are alive

scene(canvas, { objects, layouts, links }) from @remold-ui/canvas. Switch layout mid-flight and it turns round smoothly. Hover to lift a piece, click to focus it, drag to turn the scene (flick it), or Tab in and use the arrow keys.

Rebuilt from cubes

scene.points(cubes): each new cube is paired with the nearest old one (matchPoints), so the shape rebuilds instead of popping.

In-between

Drag the slider. The dot is lerpPoint(start, end, t) from @remold-ui/core.

Shape morph

createMorph(a, b) parses both shapes, pairs their pieces, matches point counts and start points, then each frame is one lerp over a Float32Array.

Springs

value() with { duration, bounce }. Click the track to send the ball to the other end. Click again mid-flight: it turns round without jumping, because the new move starts from where it is, at the speed it is going.

Throw

Drag the handle. Past the ends it resists (rubberband). Let go with a flick and it lands on the stop the flick would coast to (velocityTracker → project → release).

What became what

matchNodes(before, after) with no ids, keys or names. Matched elements share a colour; hover one to light up its partner. Grey means unmatched (removed or added); a red outline is a wrong match. Switch the matcher to compare with the two baselines.
