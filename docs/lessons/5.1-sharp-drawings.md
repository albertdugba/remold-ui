# Lesson 5.1 · Sharp drawings (script for Claude)

**Files:** `packages/canvas/src/crisp.ts` (`backingSize`, `fitCanvas`).
**Goal:** Albert can explain the two sizes of a canvas and why the pixel ratio is capped.
**Mode:** fast. The code is written and passing, so teach by story → predict → read → break it → run. One step per message, then wait.
**Code standard:** production open source. No lesson references in `packages/`.

## A · Story
A canvas is a sheet of graph paper stretched over a box. On a 2× phone each CSS pixel covers four real dots, so a 300-square sheet stretched over 600 dots looks fuzzy. Give it 600 squares.
## B · Read
- `backingSize` is pure, so it's tested without a browser. Predict `backingSize(300, 150, 3)`. *(600 × 300: capped at 2×.)* Why cap? *(3× costs 2.25× the pixels for almost no visible gain.)*
- `fitCanvas` only resizes when needed. Ask why. *(Setting `canvas.width` clears it.)*
- Verified in Chrome at 2×: a 720 × 460 canvas stored 1440 × 920.
