# Lesson 4.6 · Everyone can use it (script for Claude)

**Files:** `packages/dom/src/a11y.ts` (`announce`, `prefersReducedMotion`, `resolveReducedMotion`) and the reduced-motion and focus paths in `transition.ts`.
**Goal:** Albert can describe what each group of users gets.
**Mode:** fast, as in 4.1.

## A · Reduced motion
Movement makes some people dizzy, but they still need to *see what changed*. So with reduced motion, nothing moves: arrivals fade in, departures fade out, and changed text fades in. Verified in Chrome: the first frame was already at the final position.
## B · Screen readers
`announce: true` says "15 moved, 3 removed" through a polite live region. Ask: why clear the region first? *(So the same message twice is still announced.)*
## C · Focus
If the focused button was replaced, focus moves to its match, so keyboard users don't lose their place.
