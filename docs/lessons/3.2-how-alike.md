# Lesson 3.2 · How alike? (script for Claude)

**Files:** `packages/core/src/match/text.ts` and `similarity.ts`, tested in `match.test.ts`.
**Goal:** Albert can score any pair by hand, roughly, and say which signal dominates.
**Mode:** fast, as in 3.1.

## A · Text (`textSimilarity`)
- Predict before running: "Fix login timeout" vs "Login timeout fix"? *(1. Words in any order.)* "Update pricing page" vs "…copy"? *(High: containment.)* "Showing 6 of 6" vs "Showing 3 of 6"? *(0.55: same shape, numbers masked.)*
- Character pairs (`bigramSimilarity`) catch typos, but fade on long text. Ask why. *(Two long English paragraphs share lots of character pairs by chance.)*
- Stopwords: "the", "to"… say nothing about identity.

## B · The whole score (`baseSimilarity`)
- Weights: content 0.45, kind 0.15, position 0.2, paint 0.2.
- **The gate:** position and paint only count in proportion to how plausible the content is. Ask him for a page where removing the gate would cause a wrong match. *(A list where every row is replaced by new text: same slots, different items.)*
- The kind table: a photo never becomes a heading (0).

## C · Break it
Set the gate to always 1. Run the benchmark test and read which scenario drops.
