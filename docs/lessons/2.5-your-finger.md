# Lesson 2.5 · Your finger (script for Claude)

**Files:** `packages/core/src/motion/gesture.ts` (`velocityTracker`, `project`, `rubberband`, `deceleration`) and the "Throw" section of `apps/playground`.
**Goal:** Albert can build a drag with velocity, projection and resistance.
**Mode:** fast, as in 2.1.

## A · velocityTracker
- Speed = distance ÷ time over the **last 100 ms** only. Ask: why not the whole drag? *(A slow start would water down a fast flick.)*
- `velocity(now)` returns 0 if the finger paused before letting go, so there's no surprise fling.
- 🐛 This code had a real bug during the build: it kept a 600 ms-old sample as its reference point. Show him the test "only counts the recent window" and ask him to work out what the old line `samples[1]` did wrong.

## B · project
"Where would this flick coast to?" `(v / 1000) × d / (1 − d)`. Predict `project(1000)`. *(499.)* The playground snaps to the stop nearest the projected landing, not the nearest to where you let go. That's why a small flick still moves to the next stop.

## C · rubberband
Past the edge, the content follows at about half speed at first, then more and more slowly, and never passes `dimension`. Drag the playground handle past either end.
