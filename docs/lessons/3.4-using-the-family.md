# Lesson 3.4 · Using the family (script for Claude)

**Files:** `packages/core/src/match/structure.ts` (`structureContext`, `withContext`).
**Goal:** Albert can explain the three kinds of family evidence, and why only content-carrying descendants vote.
**Mode:** fast, as in 3.1.

## A · Story
Three "Get" buttons look identical. But you know which card is which (they have different titles), so the button in the "Notes" card goes with the "Notes" card. Matches we're sure about decide the ones we're not.

## B · Read the bonus
1. **Matched parent:** same parent pair, and a similar position inside it.
2. **Anchors:** the nearest matched sibling with content (the label beside a switch). Same row or column counts as 4× closer.
3. **Descendant votes:** containers whose contents moved together.
- The bonus is scaled by how plausible the pair already is. Ask why. *(Context should tip close calls, not invent matches.)*
- Only content-carrying descendants vote. Ask why. *(Empty boxes would vote for whatever was guessed last round, which makes guesses reinforce themselves.)*
- Three passes: each can settle ties the previous pass exposed.

## C · Break it
Set `structure: false` in the "three identical buttons" test. Predict the result, then run it.
