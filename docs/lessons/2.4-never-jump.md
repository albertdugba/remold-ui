# Lesson 2.4 · Never jump (script for Claude)

**Files:** `packages/core/src/motion/value.ts` (`value`, with `to`, `set`, `hold` and `release`) and `motion.test.ts` (the `value` tests).
**Goal:** Albert can explain interruptibility and velocity hand-off, the most important motion rule in the library.
**Mode:** fast, as in 2.1.

## A · Story
You throw a ball to a friend, then shout "no, to me!" halfway. A real ball doesn't teleport back to your hand and start again: it slows, turns round and comes back. `to()` never resets the position or the speed.

## B · Predict, then read the test
"is interruptible": after 0.1 s heading to 100, we call `to(0)`. Does the next frame move it forwards or backwards? *(Forwards for a moment. It still has speed that way.)*

## C · Hold and release
- `hold()` is a finger grabbing the ball mid-flight: simulation stops and `set()` follows the finger.
- `release({ velocity })` hands the finger's speed to the spring, so a throw carries on smoothly.
- `set()` is also the **reduced-motion** path: jump straight to the end, so people still see what changed without the movement.

## D · Break it
In `to()`, add `state.velocity = 0`. Which test fails? Try it in the playground's Springs section: click the track twice quickly and see the jerk.
